Accessibility

The MVP uses semantic headings, labels, fieldsets, status regions, keyboard-operable controls, and text that remains usable without visual styling.

If a form, status update, document, or government response is inaccessible, contact the responsible FOI office and include the page or request reference plus the format you need.

Current work

Formal WCAG testing, assistive-technology testing, Filipino-language review, and accessible document remediation remain release-gate work before broad production rollout.
