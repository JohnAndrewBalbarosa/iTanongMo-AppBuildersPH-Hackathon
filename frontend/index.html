Public information, easier to request and manage

Send one FOI submission to one or more government agencies. Each agency receives an independent request, deadline, conversation, disposition, and appeal record.

Start an FOI request

How it works

  1. Describe the records you need.
  2. Search and select up to 10 agencies.
  3. Review every field and submit.
  4. Keep each reference number and track the official response.

Designed for gradual migration

The existing government workflow can continue while selected agencies move to two-way case management, deterministic triage, a Kanban board, audit history, and optional isolated AI assistance.

Low operating cost

The public frontend consists of static files on GitHub Pages. A compact Rust service and SQLite database run the application backend on a small VPS. This keeps the MVP simple to operate while retaining backups, audit events, health checks, and a path to scale.
