About iTanongMo

iTanongMo is an MVP for gradually replacing one-way email forwarding with traceable two-way FOI case management.

For citizens

Create a request, choose several agencies when needed, receive separate references, and follow public status, messages, and decisions.

For government offices

Receive requests in a Kanban workflow, keep an audit history, use recall-oriented deterministic triage, and optionally ask an isolated AI model for draft assistance. Officials remain accountable for every sent response and disposition.

Canary rollout

Agencies and users can move in controlled groups. The legacy Rust-rendered path remains available while the static GitHub Pages frontend and versioned Rust API are validated.

Maintenance proposal

Static hosting removes a frontend server and build runtime. One Rust binary, SQLite in WAL mode, scheduled encrypted off-site-ready backups, health checks, and bounded logs fit a small VPS. Growth can later move files or the database without changing the public API contract.
