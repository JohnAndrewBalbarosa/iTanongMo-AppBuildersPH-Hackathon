Privacy notice for the MVP

The service stores contact details and request contents needed to receive, process, audit, and respond to an FOI request. Do not include passwords, API keys, or unrelated sensitive personal information in an FOI request.

Requester AI

The provider token exists only in the current tab's JavaScript memory for up to 15 minutes. The frontend does not write it to browser storage. The Rust relay does not persist or log it. During generation, the token and draft details are transmitted over HTTPS to the Rust API and the selected external AI provider. AI output can be incorrect and is never submitted automatically.

Government AI

Government-side AI uses an isolated configured model and creates reviewable drafts. A government official must verify and explicitly publish a response.

MVP limitation

Identity verification and eGov integration are post-MVP controls. This deployment must remain a canary until those controls and a production privacy assessment are complete.
